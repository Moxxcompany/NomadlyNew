── SMS-TO-TELEGRAM: BEHIND THE SCENES ──────────────────

  1. Someone texts +1 (212) 555-0142
  2. Telnyx receives it, fires webhook:
     POST https://pod-url/api/telnyx/sms-webhook
     Body: { from, to, text, ... }
  3. FastAPI proxy strips /api → Node.js Express receives it
  4. Node.js handler:
     a. Looks up +12125550142 in phoneNumbersOf collection
     b. Finds owner chatId = 5590563715
     c. Checks features.smsForwarding config
     d. If toTelegram: true → bot.sendMessage(chatId, formatted)
     e. If toEmail: set → nodemailer sends email
     f. If webhookUrl: set → axios.post(url, payload)
     g. Logs in phoneLogs collection
  5. User sees the message in Telegram instantly
